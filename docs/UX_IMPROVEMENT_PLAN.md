## 2. 設計方針

1. **既存キーバインドは 1 つも変えない**。新機能には空いているキーだけを割り当てる。
2. **「どこで何が起きているか」を常に一目で分かるようにする** — ペインの状態（実行中/終了コード/未読出力/ベル）をタブ・ペイン見出し・オーバービュー・ステータスバーの全てで同じ規則で表示する（`services/paneInfo.ts` に集約）。
3. **キーボードファースト + 発見性** — すべての操作をパレットから検索でき、ツールチップとヘルプにショートカットを併記する。
4. **端末の作業を邪魔しない** — モーダル表示中に裏のシェルへキー入力が漏れない、検索ハイライトでクリップボードが上書きされない、フォーカスが必ず戻る。
5. **一つの真実の源** — 色は CSS 変数、キー表示は `keymap.ts`、ペイン状態は `PaneStateStore`。

## 3. Phase 1（今回実装済み）

### 新機能（ターミナルマネージャとして新しい体験）
- **ペイン・オーバービュー `Ctrl+Shift+O`**: 全タブの全ペインを 1 層のカードグリッドに並べる。各カードに 500ms 間隔で更新されるライブ出力プレビュー、タブ識別色、タブ内の位置を示すミニマップ、シェル種別、cwd、未読出力/ベル/終了コード、最終出力時刻。文字入力で名前・ディレクトリ・コマンド・**出力内容**を横断絞り込み。矢印キー（2D 移動）/ `1`〜`9` 直接ジャンプ / `Ctrl+Shift+W`・Delete・中クリックで閉じる。
- **クイックスイッチ `Ctrl+Tab`**: Alt+Tab 方式。押し続けると MRU 順のカードを表示、Tab/Shift+Tab で巡回、Ctrl を離すと確定。一瞬のタップなら一覧を出さず直前のペインへ。
- **シェル統合**: cmd は `PROMPT`、PowerShell は `prompt` 関数のラップで OSC 9;9 を自動送出。分割は「今いるディレクトリ」で開き、終了時の各ペインの cwd を保存して次回復元。`ELECXTERM_NO_SHELL_INTEGRATION` で無効化可能。
- **ペインのズーム `Ctrl+Shift+Z`**、**ペインを新しいタブへ移動**、**分割の均等化**。
- **ペイン内検索 `Ctrl+Shift+S`**（大文字小文字/単語/正規表現、件数表示）。
- **コピー/ペースト**（`Ctrl+Shift+C`、選択中の `Ctrl+C`、`Ctrl+V`、`Ctrl+Shift+V`、離した時点での自動コピー）。
- **終了したシェルの再起動**（Enter / ボタン、終了コード表示）。pwsh 未導入時は Windows PowerShell に自動フォールバック。
- **ショートカット一覧 `Ctrl+Shift+?`**、**タブ番号ジャンプ `Ctrl+Alt+1..9`**、新規タブのシェル選択メニュー。

### UI の刷新
- タブをタイトルバーに統合（縦 36px 節約）。タブにはアクティブペインのタイトル（実行中コマンド or ディレクトリ名）を自動表示、手動命名で固定、ダブルクリックでリネーム、中クリックで閉じる、「他のタブを閉じる」。
- ペイン見出し（シェルバッジ・タイトル・cwd・状態・ホバー時の操作ボタン）。非アクティブペインを減光してフォーカス位置を明確化。見出しはパレットから非表示にできる。
- コマンドパレット: fzf 風あいまい検索とハイライト、最近使ったコマンド、カテゴリ見出し、ペイン/タブへのジャンプ。
- ステータスバー: アクティブペインのシェル/cwd（クリックでコピー）、ズーム状態、未読ペイン数（クリックでオーバービュー）、テーマ切替、ヘルプ。
- 配色を再設計（中立寄りのダーク/ライト、成功/警告/危険/情報の意味色、キーキャップ、影）。UI フォントを Segoe UI 系のシステムフォントに変更し、Google Fonts への実行時依存を撤廃。`prefers-reduced-motion` に対応。
- トーストを積み重ね式・種類別アイコンに。

## 3.5 Phase 1.5（追加実装済み）

- **タイトルバーのナイト/ライト切り替えボタン**: 太陽/月アイコンが回転して入れ替わり、押した位置から円形に広がる View Transition でテーマを切り替える（端末の配色も同じフレームで切り替わる）。アニメーション削減設定時は即時切り替え。
- **設定パネル `Ctrl+Shift+.`**（タイトルバーの歯車）: テーマカード、フォントのプリセット（未インストールは薄く表示）とライブプレビュー、サイズ、行間、カーソル形状/点滅、ペイン見出し、非アクティブペインの減光（なし/弱/強）、開始ディレクトリ（「現在のディレクトリを使う」ボタン付き）、リセット。従来のテキスト入力ダイアログ（フォント/開始ディレクトリ）を置き換え。
- **タブの色分け**: タブの右クリックメニューで 8 色から選択。タブの上端ラインとオーバービューのカードに反映。
- **「最下部へ戻る」ボタン**: スクロールバックを遡っている間だけペイン下部に表示。
- **ウィンドウ非アクティブ時のタイトルバー減光**（ネイティブアプリと同じ作法）。
- 減光は端末本体だけに掛け、検索バーや終了バナーは常にくっきり表示するよう修正。ステータスバーのテーマ切り替えはタイトルバーへ移したため削除。

## 3.6 Phase 1.6（追加実装済み）

- **長時間コマンドの完了通知**: シェル統合に OSC 133（A=プロンプト開始 / B=入力開始 / D=終了・PowerShell は終了コード付き）を追加。プロンプト上の Enter を開始とし、次のプロンプトで完了とみなして所要時間を計測。見ていないペインのコマンドが設定秒数（既定 10 秒）以上かかって終わると、アプリが前面ならトースト（「Show」で該当ペインへ）、裏にあれば OS 通知 + タスクバー点滅。オーバービューのカードに「▶ 実行中のコマンド・経過時間」「✓/✗ 直前のコマンド・所要時間」を表示。
- **端末の配色プリセット**: GitHub / Catppuccin / Solarized（UI のライト・ダークに追従）と One Dark / Dracula / Tokyo Night / Nord / Gruvbox。設定パネルに見本付きのグリッドで表示し、フォントのプレビューにも反映。
- **Windows 11 の Mica / Mica Alt**: 設定でウィンドウ背景を Solid / Mica / Mica Alt から選択。クロム部分とペイン間の余白だけを半透明にし、端末本体は不透明のまま（文字の鮮明さを維持）。Windows 11 以外では選択肢自体を出さない。
- 開発環境: この PC に Rust（rustup / stable-msvc）と VS 2022 Build Tools を導入し、Rust 側のビルド・テストをローカルで実行できるようにした。

## 3.7 Phase 1.7（0.0.18 リリース前の仕上げ）

- **設定パネルのショートカットを `Ctrl+Shift+.` に変更**（ユーザー指定）。同じキーだった「最後のペインへ移動」は `Ctrl+Shift+End` に移し、対になる「先頭のペインへ移動」に `Ctrl+Shift+Home` を追加（`Ctrl+Shift+<` も引き続き有効）。
- **実行中コマンドがあるペイン・タブを閉じる前に確認**: シェル統合で分かる実行中コマンド名を一覧表示し、Enter で閉じる / Esc で取り消し。ショートカット・ペイン見出し・タブ・オーバービュー・パレットのすべての閉じる操作に適用。
- **フォントサイズ変更時の HUD**: 画面中央に現在のサイズを一瞬表示。
- **初回起動時のウェルカムカード**: オーバービュー / クイックスイッチ / パレット / 設定のショートカットを紹介（一度閉じたら再表示しない）。

## 4. コード精査で見つけた問題と対応

| 区分 | 内容 | 対応 |
| --- | --- | --- |
| 不具合 | タブ名変更の入力で IME 確定の Enter が確定扱いになる | `isComposing` を判定 |
| 不具合 | タブ名変更を Esc で取り消しても blur で確定されうる | キャンセルフラグで抑止 |
| 不具合 | パレット/プロンプト/メニューを閉じた後に端末へフォーカスが戻らない | 端末側で再フォーカス（オーバーレイ表示中は抑止） |
| 不具合 | 選択の自動コピーが検索ハイライト等のプログラム選択でも走る | マウスを離した時点でのみコピー |
| 不具合 | cmd でペースト手段がない（Ctrl+V が ^V として送られる） | WT 互換のコピー/ペーストを実装 |
| 不具合 | デバウンス中にウィンドウを閉じると直前の変更が保存されない | `onCloseRequested` で保存をフラッシュ |
| 不具合 | アプリのカレント（インストール先/System32）でシェルが開く | 既定をホームディレクトリに |
| 不具合 | pwsh 未導入だと PowerShell 分割が赤枠になるだけで理由不明 | フォールバック + 端末内にエラー表示 |
| 不具合 | フロントのリロード後、同じ ID の PTY が残り出力が届かない | 重複 ID は破棄して作り直す |
| 不具合 | 処理済みショートカットの一部（T/D/E/W/</>）が xterm にも流れていた | 処理したキーは常に `stopPropagation` |
| 不具合 | モーダル表示中もペイン操作のショートカットが裏で効く | オーバーレイ表示中は開閉系以外を無効化 |
| アンチパターン | 子プロセス終了を 120ms ポーリング × ペイン数、読み取りごとに blocking タスク生成 | 専用スレッド + `wait()` + `ChildKiller` |
| アンチパターン | xterm を DOM 外で open → 24x80 で PTY 起動 → 直後にリサイズ | ホストに貼ってから同期生成し、正しいサイズで起動 |
| アンチパターン | `fit()` 後に PTY リサイズを二重送信（同サイズ時は Rust 側で ±1 行の揺さぶりが起きる） | xterm の `onResize` に一本化 |
| アンチパターン | xterm 配色を CSS 変数と手動同期 | CSS 変数から生成 |
| アンチパターン | ThemeContext の値・`setTheme` が毎レンダ新規生成 | `useCallback`/`useMemo` |
| 重複 | タブバーの外側クリック処理が backdrop と window リスナーで二重 | backdrop に一本化 |
| 重複 | ツリー走査ヘルパーが各所に散在 | `paneInfo.ts` に集約 |
| 冗長 | 未使用の型（Session/SessionStore/PaneState/`command`）、未使用依存（uuid, @types/uuid, Rust の uuid/log/serde_json） | 削除 |
| 実装漏れ | ペイン操作がアクティブタブ限定 | 任意タブのペインを操作可能に |
| 実装漏れ | 終了コード、ウィンドウタイトル、ベル、ブラウザでの UI 開発手段 | 追加（`npm run dev` でモック動作） |

## 5. 今後のロードマップ

### Phase 2（次に効果が大きいもの）
- **ブロードキャスト入力**: 選択したペイン群（オーバービューで複数選択）へ同時入力。
- **ペインのドラッグ&ドロップ**: オーバービュー上でカードを別タブへドロップして移動/結合。
- **空間ナビゲーション**: 方向キーによる隣接ペインへのフォーカス移動（キー割り当ては要相談）。
- **プロファイル**: WSL / Git Bash / 任意コマンドをシェル選択メニューに追加、タブ色の手動指定。

### Phase 3（差別化）
- **ワークスペース（名前付きレイアウト）** の保存・切り替え、起動時コマンド付きのレイアウトテンプレート。
- **OSC 133 によるコマンドブロック**: コマンド単位のジャンプ・コピー・終了コード表示。
- 設定パネルへの追加: シェル統合の ON/OFF、既定シェル、スクロールバック行数、配色のインポート（Windows Terminal / iTerm2 形式）。
